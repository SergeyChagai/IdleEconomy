# Дорожная карта

Проект: система экономики и прогрессии для Roblox (Luau + Rojo + Knit).
Закрытые спринты отражают фактически сделанное, а не план.

## Sprint 1 — Ядро экономики

Goal: чистая математика экономики, покрытая тестами без запуска Studio

- [x] Balance: экспоненциальные цены, доход, престиж, оффлайн-начисления
- [x] Замкнутая формула суммы с доводкой против ошибки округления
- [x] Wallet: ООП-класс с валидацией и атомарными операциями
- [x] Модули без require — грузятся и в Roblox, и в Lune
- [x] Тест-раннер describe/it/expect без внешних зависимостей
- [x] Прогон из консоли с кодом возврата для CI

Sprint 1 status: closed

## Sprint 2 — Серверный слой и защита ремоутов

Goal: сервер владеет состоянием, весь ввод клиента валидируется

- [x] Validate: типы, диапазоны, целочисленность, длина идентификаторов
- [x] EconomyService на Knit — единственный владелец состояния
- [x] Клиент присылает намерение, стоимость считает сервер
- [x] EconomyController: интерфейс и отправка намерений
- [x] Ручная добыча по клику как стартовый источник дохода
- [x] RateLimiter: дырявое ведро против автокликера
- [x] Проверка мутацией: подтверждено, что тесты умеют падать

Sprint 2 status: closed

## Sprint 3 — Персистентность

Goal: прогресс игрока переживает рестарт сервера, оффлайн-доход начисляется

- [ ] Схема профиля с номером версии
- [ ] Миграция ключей между версиями схемы
- [ ] Загрузка и сохранение через ProfileStore
- [ ] Автосейв по таймеру и на выходе игрока
- [ ] Начисление оффлайн-дохода при входе через Balance.offlineEarnings
- [ ] Тесты миграции: старые версии, битые данные, пропущенные ключи
- [ ] Тесты: повторная загрузка не удваивает оффлайн-начисление

Sprint 3 status: in progress

## Sprint 4 — Монетизация

Goal: покупки за Robux начисляются ровно один раз

- [ ] Идемпотентный ProcessReceipt с историей PurchaseId
- [ ] Геймпассы: множитель дохода и расширенный оффлайн-потолок
- [ ] Dev products: пакеты валюты
- [ ] Аналитика покупок
- [ ] Тесты идемпотентности: повтор, гонка, рестарт между попытками

Sprint 4 status: planned
